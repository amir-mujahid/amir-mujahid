Featured Project

Cogniv — AI-Powered Academic Platform

September 2026 – Present · In active development

Cogniv is my first SaaS product: an AI-native academic platform designed to bring student productivity, learning, research, collaboration, and academic analytics into one connected experience across web and mobile.

What I'm building:

- Intelligent planning: Timetable management, task prioritisation, vision-based OCR schedule extraction, transit alerts, and calendar synchronisation.
- AI-powered learning: Structured notes, stylus-based handwriting, AI-assisted ink-to-LaTeX transcription, spaced repetition, and exam preparation.
- Research and knowledge management: Course-specific file vaults, academic paper reading, and BibTeX bibliography export.
- Collaboration and productivity: Study groups, shared resources, real-time collaboration, focus timers, and campus navigation.
- Academic analytics: GPA tracking, CGPA what-if simulations, and achievement tracking.
- Career tools: Portfolio building, ATS-oriented CV generation, and third-party integrations.

Tech stack: Next.js · React · TypeScript · Kotlin · Jetpack Compose · Node.js · FastAPI · Python · PostgreSQL · pgvector · MongoDB · Redis · Groq · NVIDIA NIM · Gemini · Azure · Docker
